# Benzo Logistics

Luxury blue-and-white Next.js website for Benzo Logistics, a Sandringham, Johannesburg logistics business.

- Fleet: two bakkies, one trailer, and an 8-ton truck
- Pricing: from R500, distance-based and negotiable
- Contact: 063 446 9218 / 068 666 0141

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000. Deploy the frontend by connecting this repository and the `initial-setup` branch to Vercel.
